## Carpetas

```
Evidencias/
  Antes/       Capturas del estado inicial del prototipo
  Despues/     Capturas del estado ajustado
  Documentos/  Cuestionario, informes, guía e infografía (md + docx + pdf)
```

## Pendientes de completar por la aprendiza

1. **Activar la licencia de Unity** (abrir Unity Hub e iniciar sesión) para poder
   generar las 4 escenas y la build WebGL.
2. Generar las escenas con **NitroRhythm ▸ Build Prototype Scenes**.
3. Compilar con **NitroRhythm ▸ Build WebGL** y publicar el enlace.
4. Aplicar el cuestionario a los **5 usuarios** y anexar la analítica.
5. Capturar **Antes/Despues** con **NitroRhythm ▸ Evidence Capture Tool**.
6. Montar la infografía en Canva con las imágenes y el contenido de AA4.
